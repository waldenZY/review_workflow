# Eval Studio · 标准库与分组批跑

项目内管理已有内容的评测工作台，使用 FastAPI、SQLite 和原生 JavaScript；源码部署，无前端构建步骤。

**创建项目 → 导入数据与字段方案 → 设计独立标准 → 保存分组批跑方案 → 各组绑定字段 → 试跑／批跑 → 历史与导出。**

## 启动

Python 3.10+。当前 Windows 开发使用 moto：

```powershell
$motoPython = 'D:\Application\Anaconda3-5.3.1-Windows-x86_64\envs\moto\python.exe'
& $motoPython -m pip install -r requirements.txt
& $motoPython scripts/start.py
```

Linux：

```bash
python -m pip install -r requirements.txt
python scripts/start.py --host 0.0.0.0 --port 8000 --data-dir "$HOME/eval-studio-data"
```

访问 `http://127.0.0.1:8000`。侧栏提供教程和部署说明；接口文档位于 `/docs`。

**存储修订 4，不迁移旧数据。** 数据位置仍为 `数据根目录/v1_1/workbench_v1_1.sqlite3`。上线前由部署人员停服、完整备份并清空旧业务目录；程序遇到旧版本或未知结构拒绝启动，不删除或重建旧库。独立保留 `config/llm_config.local.json`。完整步骤见 [Linux 部署](docs/Linux部署.md)。

## 标准、分组与测试

- 每条标准是独立资源，保存名称、判断描述、评测方式及输出模板；支持追加版本、另存为、归档恢复和引用保护删除。
- 批跑方案固定引用标准的具体版本，保存有序分组和共用 System／User 消息，不保存数据、字段或模型。更新标准后，已有方案保持原版本；可查看变化后更新引用并保存。
- 一个组一次模型请求，单标准组即单独执行。五条标准可组合为 `[1,3] [2] [4] [5]`、五个单组或 `[1,2,3,5] [4]`，每行分别请求 4、5、2 次。各组输入独立，组间不传递输出。
- 执行选择一个数据集，各组分别选该数据集下的字段方案。所有组共用提交时的全局模型和并发上限；不同运行按 FIFO 排队。
- 标准支持 LLM、程序非空和程序 JSON Schema。混合组先执行程序规则，业务不通过不阻止模型；纯程序组不调用模型。
- “测试此标准”可直接测试合法草稿，输入为粘贴 JSON 或数据集一条记录。单次调用，无自动重试，独立测试记录和独立单请求通道。执行页“试跑选中第 1 条”验证全部组的真实组合，作为试跑运行保存。

LLM 模板支持 `choice:[...]`、`multichoice:[...]`、`value:string`、`value:number`。每条标准可不同，平台按标准名称组合严格 JSON。业务取值直接展示，不翻译成固定四值，不做业务评分汇总。规范和负责人交付提纲见 [标准设计规范](docs/评测标准与输出模板规范.md)。

## 运行与结果

调度单位为“一条数据 × 一个组”，有界派发，网络期间不持有数据库写锁。严格拒绝解释文字、代码围栏、重复键、非有限数值和结构不符；任一标准格式错使本组技术失败，同一行其他成功组保留结果。

首轮组任务结束后，仅失败且有额度的组追加自动重试轮次，进入 FIFO 队尾。每行每组最多追加 **3 次**；成功组跳过，预算持久化。人工重试只补失败／未完成组，不重置预算；新建运行重新获得额度。试跑、取消、重启中断、调度和持久化异常不自动续跑。取消停止新派发并保存全部在途结果；重启后未完成任务标记中断，等待人工操作。

结果一条源数据一行，表头按执行组／标准／字段排列，展示组状态与错误、完整 JSON、字段和版本、请求响应及尝试。历史详情在独立弹窗中查看；载入编辑恢复为草稿，不自动执行。分页先限制源行，再读取组结果；导出分批读取。

JSON、JSONL、XLSX 单文件导入最大 100 MiB。XLSX 按标准字段顺序展开为 `result/标准名/字段名`（JSON Pointer 转义），保留数值类型、多选 JSON 文本及完整 JSON；JSONL 保存嵌套输出和组级元信息。两种格式包含整个源数据集，保留失败、取消未执行及未选中记录；列冲突拒绝覆盖原数据。

## 全局模型与项目隔离

命名模型配置包含原有八字段：`api_url`、`api_key`、`model`、`max_tokens`、`timeout`、`stream`、`enable_thinking`、`skip_special_tokens`。地址是完整调用 URL；后两项放入 `extra_body`，不加 `response_format`。保存、启用和连接测试为独立操作；密钥留空保留同一配置原值。批跑并发 `execution.batch_concurrency` 为 1～32，不发送给供应商。

密钥只进入本地连接文件和运行内存，不进入业务快照或导出。原配置重试固定原公开模型参数、分组及字段；更换密钥允许重试，公开参数改变需恢复或新建复测。项目间不共享业务对象；项目归档后可查看和导出，有运行中任务时拒绝归档或删除。
