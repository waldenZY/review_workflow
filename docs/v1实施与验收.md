# v1 实施与验收

日期：2026-10-29。本文记录当前 v1，取代 v0 的操作与协议约定，历史交接文档仍保留。

## 已实施

- Python＋原生 HTML/CSS/JavaScript，单进程单队列，源码直接部署；新增 Markdown 运行依赖提供页面帮助。
- 新数据库 workbench_v1.sqlite3；项目有名称、说明、时间、归档状态及对象计数；实体、版本、运行、导出和审计均按项目查询和校验。
- 项目下分类保存数据集、字段配置、标准方案、评测器、运行和设计调用；不设任务层，不允许跨项目引用、移动或共享业务对象。
- 项目切换保存各项目最近对象选择，放弃草稿需确认；轮询和项目异步响应通过项目 epoch 防止串入新项目。
- 项目归档只改变项目状态，子对象归档状态独立保留；存在未结束任务或设计调用时阻止归档删除。
- 整项目删除需范围预览和名称确认，不受内部引用阻断；单对象删除仍检查全部版本及保留运行的引用。
- 文件归属路径限制和链接检查，删除先暂存再提交，失败回滚；清理残余明确返回 file_cleanup_pending。
- 全局八字段模型设置可保存热加载、密钥留空保留及独立清除；真实调用支持普通 JSON 和 SSE，无启动探测、自动重试、降级或 response_format。
- 每个设计调用、每次运行捕获不可变连接；队列仅在内存持有密钥，SQLite 只保存公开参数和指纹。重启后未完成任务中断，重试检查公开指纹。
- 共同评测字段取代三角色；一条记录的所有 LLM 标准共用一次调用；非空和 JSON Schema 规则独立执行，不调用模型。
- 显式 System/User 模板仅使用 criteria、fields、response_schema 变量，一次替换，不在模板之外拼接生成任务 Prompt。
- 消息预览和结构示例不调用模型；返回 Schema、路径映射和自定义示例放高级区。
- 提取、依据分析及 Judge 共用空白/BOM、完整代码围栏规范化和严格 JSON 解析，保留原文、规范化结果、结构及投影错误。
- 执行与基本预览、取消、重试、选中复测、XLSX/JSONL 导出在同页；未执行和失败行保留，导出不附带未选择列的业务快照。
- 标准、评测器版本及内容对比，设计调用持久记录，候选恢复为未保存草稿；操作记录无身份系统。
- 使用帮助侧边面板与 /help/tutorial、/help/deployment 共同渲染仓库 Markdown，无外网资源依赖。
- 删除产品模拟、故障注入、演示数据、人工复核、案例及其接口；删除现有自动测试及 pytest 依赖，不建立新测试套件。
- 不读取或迁移旧数据库，不保留旧业务格式兼容代码，不删除旧库及其文件。

## 关键接口

全局：/api/v1/health、/api/v1/projects、/api/v1/llm/config、/api/v1/llm/status、/api/v1/llm/clear-key、/api/v1/llm/test。

项目接口统一位于 /api/v1/projects/{project_id}/：catalog、datasets、mappings、specs、evidence/analyze、evaluators、requests/preview、runs、history、entities；具体参数见运行后的 /docs。旧无项目业务路由已移除。

字段配置使用 evaluation_fields；标准无 required_roles；评测器使用 system_template、user_template、response_schema、projection 和可选 output_example。新接口不接受 execution_mode 或模拟参数。

导出接受 format=xlsx|jsonl、original_fields=null|列名数组、include_raw_response=false。null 保留全部原始列；自定义时服务端强制并入评测字段所属顶层列。JSONL 格式为 original 与 evaluation 两个对象，XLSX 追加 eval.* 列。

## 验收方法与结果

按用户约定采用人工操作和静态检查，只复用一条自建业务记录，项目隔离可在两个项目导入同一条记录。不读取外部数据集、不批跑全量、不建立自动测试或故障注入入口、不自动发送真实模型请求。

本轮在 moto 环境下完成以下临时目录人工接口联调和静态检查，没有保留测试脚本或新测试套件：

- 通过 Python 单独启动服务；首页、JS、CSS、两份帮助 HTML 均返回 200，帮助的七个章节定位存在。
- 同一条自建记录分别以 JSON、JSONL、XLSX 导入，单记录及数组结构保留；CSV 返回 400。
- 两个项目列表隔离，跨项目详情读取和字段引用返回 404，旧无项目 catalog 路由返回 404。
- 保存字段、标准、评测器，静态预览包含两条消息；未选内部列、生成任务 Prompt 和设计备注未进入 Judge 消息。
- 单条非空和 JSON Schema 规则执行完成、结果通过，model_called=false；选中样本新建复测完成并关联原运行。
- XLSX 与 JSONL 导出保留行序和强制评测列，自定义排除内部列；JSONL 保留嵌套对象，原始响应默认不导出。
- 标准保存新版本，比较接口返回标题差异；归档项目后的写入返回 409，导出仍可用，项目恢复后子标准保持单独归档状态。
- 单对象引用保护返回 409；整项目删除名称错误返回 400，正确确认后清理所属目录、业务表及项目审计，仅保留最小全局删除事件，其他项目保留。
- 重启同一临时数据目录后，项目、数据集、两次已完成运行和尝试可重新打开。只创建 v1 数据库，没有读取或生成旧数据库。
- 使用仅用于本地配置校验的无效服务地址和临时字符串验证配置保存、错误配置不覆盖、校验响应不回传密钥、清除密钥及严格布尔类型；未点击连接测试、未访问该地址。数据库字节检查未发现该临时字符串。
- 直接检查捕获的连接对象：后续设置变化不改变已捕获对象，轮换密钥不改变公开指纹。实际在途 HTTP 调用期间的切换仍未做服务验收。
- 手工输入纯 JSON、完整围栏、BOM、非法 JSON 和解释文字检查解析边界；Schema 不匹配、投影缺失和外部 Schema 引用均得到明确错误。
- Python 编译和原生 JavaScript 语法检查通过；现有测试源文件、缓存与 pytest 依赖已删除。

当前没有连接可用浏览器，未完成真实页面交互、视觉、项目切换迟到响应和帮助编辑保持的浏览器验收。没有调用真实模型，普通响应/SSE 的供应商兼容性、连接测试、真实超时及在途配置切换没有服务验收。没有连接 Linux 服务器。上述未完成项不得视为通过。

## 已知边界

无登录权限系统，适用于受控内网单用户；无并行队列或大数据性能验收。导入文件最大 25 MB，每页预览 50 条。Excel 不支持样式及公式的无损往返，单元格容量限制会报错，可选择 JSONL。取消在样本之间生效；在途单次 HTTP 不立即取消。

模板变量和 Schema 有明确支持范围，不猜取解释文本中的 JSON，不自动修复模型输出。复杂 Schema 示例可能需要用户手填，语义评测质量和供应商兼容性须实际使用人工校验。
