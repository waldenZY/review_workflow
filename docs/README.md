v1 改为项目下分类管理，真实模型执行，统一共同评测字段，合并执行与导出，页面可修改全局模型配置并打开帮助。取消模拟、演示、复核案例和自动测试，不兼容旧业务数据。

维护现有文档并通过 Git 查看历史，避免复制多个含义不明的版本。未完成的真实服务、浏览器或 Linux 验收必须明确记录。外部测试资料不复制到仓库，也不由程序自动加载。
