# 存储修订 4：标准库、分组批跑与按组重试

## 本次结果

将旧标准方案／评测器结构替换为项目内独立标准库和分组批跑方案。每条标准独立版本化，方案固定标准版本、分组顺序与共用消息；运行再选择一个数据集和各组的字段方案。一个组一次模型请求，纯程序组不请求模型。前端使用新接口，不保留旧 `/specs`、`/evaluators` 接口。

现有未提交的整行自动重试已吸收到组任务调度，每行每组最多追加 3 次，成功组保留并跳过。没有先提交或丢弃已有工作。本次不操作服务器、不自动提交或推送。

## 数据与 API

- `standard`、`execution_plan`、`mapping`、`dataset` 和 `standard_test` 复用独立对象版本机制；标准测试与运行历史分离。
- 标准新增 `/standards`、版本、模板编译、归档恢复、引用和删除接口；`/standards/test` 支持合法草稿及两种输入，单次执行、独立单请求锁。`/standard-tests` 提供分页摘要和快照详情。
- `/execution-plans` 保存组及共用消息，提供编译与组请求预览；`/runs` 接收数据集／方案版本、全部组字段绑定、样本范围及 trial/batch 模式。模型与并发由服务端捕获。
- `run_records` 保存源行定位和汇总状态，`group_tasks` 唯一定位项目／运行／数据行／组，保存状态、有效结果摘要、尝试及已用自动额度。
- 尝试增加组 ID、自动／人工轮次和指标。组结果、行状态和进度在短事务内更新，网络不持有写锁；只在已有业务事务中保存补充耗时指标。
- 调度按源行／组顺序有界派发，共享一个运行并发上限；不同运行 FIFO，自动轮次进入队尾。取消停止派发并保存全部在途结果，重启将未完成组中断，不自动续跑。
- 分页先限制源行再查组结果；过滤覆盖整次运行。导出分批读取全部原始行及组结果，原始列冲突明确拒绝。
- 存储修订为 4，目录和数据库文件名保持不变；旧版本、未知表列、约束或索引拒绝启动，不迁移、不删除、不自动重建。旧迁移命令不访问数据库。

## 页面与文档

标准库提供显式“标准描述”“输出规则模板”、合法草稿测试、独立测试历史、保存／另存／版本与管理。方案提供标准版本选择、引用更新前后内容、合并／移动／拆分和组顺序编辑，结构只读派生。执行页逐组选择字段方案及版本，切换数据集清空绑定；提供组合预览、分组试跑和正式批跑。

结果按组／标准／字段三层表头显示，成功组保留、失败／未执行组明确状态，旧尝试不作为本轮成功。历史使用暗色模糊背景弹窗，不改变编辑状态；载入编辑恢复为草稿，保存后再新建复测。XLSX 和 JSONL 保留完整 JSON、组状态、错误、固定版本与执行元信息；按需包含原始请求响应。

浏览器选择缓存命名空间更换为 `eval.v1_1.r4`，静态资源继续使用内容哈希。README、教程、标准设计规范和部署说明均改为修订 4；旧设计资料仅作历史记录。

## 验收方法与记录

日期：2026-11-18。使用 Windows moto、临时业务目录、自建 25 条记录、受控模型响应、FastAPI TestClient 和无头 Edge。不读取现有业务库、不请求真实模型、不新增依赖或永久测试套件。临时脚本不纳入仓库。

后端 50 项检查覆盖：

- 五标准三种分组每行初始请求数 4／5／2，组字段隔离及同名输出字段隔离。
- 四种模板、中文和转义、非法模板及行列错误；严格 JSON 重复键、非有限数值、外围文本与结构错误。
- 标准版本固定、显式更新引用、多方案复用、跨项目拒绝、归档执行阻止、引用保护与未引用标准删除。
- 两种单标准测试输入、未保存草稿不写标准版本、独立测试历史、不自动重试、单测试通道不阻塞在批跑后且拒绝第二个并行测试。
- 请求预览不调用模型，重复标准引用拒绝；纯程序无请求无模型结果列，混合组程序业务不通过仍调用模型。
- 一组失败保留其他组，自动最多追加 3 次且成功组跳过；人工重试不重置额度，真实关闭／重开存储后额度保留。
- 共享并发上限、取消在途收尾、未派发组保留、人工补跑只补未成功组、自动重试进入 FIFO 队尾。
- 重启中断等待人工、保存异常停止派发且不自动续跑；整次运行错误筛选、跨页源行顺序。
- XLSX／JSONL 完整源行、部分成功、未选中行、数值类型、数组、特殊字段转义、原始公式文本保护、列冲突和密钥排除。
- 新库初始化、修订 0／3／999 和结构未知的修订 4 拒绝启动且数据库字节不变；停用迁移命令不改数据。

无头 Edge 完成：打开项目 → 字段方案 → 标准草稿设计与两种输入测试 → 保存两条不同结构标准 → 加入方案、全部合并和拆开 → 保存方案 → 各组绑定不同字段 → 请求预览 → 分组试跑 → 正式批跑 → 自动额度耗尽 → 人工只重试失败组 → JSONL／XLSX 下载 → 完整 JSON 和组尝试详情 → 历史模态查看 → 载入为草稿 → 保存后保持组字段绑定。没有浏览器脚本异常；检查了三层结果表头及弹窗截图。

另做 Python 源码编译、JavaScript 语法检查及 Git 差异空白检查。没有运行真实模型质量评估、100 MiB 不同材料形态的容量测试、生产吞吐测试或 Linux 实机验收。
